## 可以练什么？

| 训练方向 | 软件提供的功能 |
| --- | --- |
| **K 线与趋势判断** | 隐藏未来走势，手动逐根推进或自动回放，练习在当时的信息下作出判断。 |
| **不同市场阶段** | 随机抽取历史区间，也可指定股票；切换日 K、周 K、月 K，反复观察行情。 |
| **买卖与仓位控制** | 使用模拟资金进行市价交易、限价挂单，观察现金、持仓和浮动盈亏。 |
| **止盈止损** | 设置止盈止损比例，或在图表上拖动对应水平线，练习交易计划和风险控制。 |
| **指标与技术分析** | 使用均线、布林带、MACD、KDJ、RSI、成交量与信号库；副图支持独立窗格、调整高度和放大。 |
| **交易复盘** | 查看操作记录、模拟收益和回撤，生成复盘报告，回看自己的决策过程。 |

## 为什么方便？

- **免费使用：** 免费下载、免费使用，不需要购买订阅才能开始本地训练。
- **本地加载更直接：** A 股历史数据随软件提供，按需读取目标股票，不必等在线行情接口返回。实际加载速度取决于电脑与硬盘。
- **断网也能练：** 本地历史回放、模拟交易和复盘不依赖原网站；联网行情只是补充功能。

- **按自己的节奏：** 手动「下一根」，或用 1× / 2× / 4× / 8× 自动回放；一局结束后可以重新抽取历史区间。
- **下次继续：** 训练进度、账户与设置保存在本地，可导出备份后换电脑或升级。

## 三步开始

1. 在 [下载页面](https://github.com/elpsycongroo4869-boop/rexim/releases/latest) 的 **Assets** 下载 `WealthTrainer-1.5.1-win-x64.zip`。
2. **完整解压**到一个可写入的文件夹，双击 `致富模拟器.exe`。不要只复制 EXE，也不要下载 `Source code` 作为运行包。
3. 进入 **A 股回放**，点击「随机抽取」，用「下一根」推进行情，再进行模拟买卖。

适用 **Windows 10/11 x64**。当前版本 **1.5.1**，下载约 **230 MB**。首次下载和解压需要时间，之后本地训练无需反复下载历史数据。

## 使用前了解

- 软件是 **模拟炒股与 K 线训练工具**，不连接真实证券账户，也不提供收益保证或投资建议。
- 历史库是随包快照，并非自动更新到最新交易日；实时行情可能延迟或不可用，「本地加载快」不代表联网行情零延迟。
- 本地昵称不是云端账号，数据不会自动跨设备同步。升级前先导出备份，分享时不要附带自己的 `UserData`。
- 本版未进行商业代码签名。请从本仓库 Releases 下载，按附件校验文件核对，不要关闭系统安全防护。

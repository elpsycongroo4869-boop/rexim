- **历史 K 线回放：** 支持日 K、周 K、月 K；隐藏未来走势，手动「下一根」或自动播放，不是一张只能回看的静态图。

## 三步开始

1. 在 [下载页面](https://github.com/elpsycongroo4869-boop/rexim/releases/latest) 的 **Assets** 下载 `WealthTrainer-1.5.2-win-x64.zip`。
2. **完整解压**到一个可写入的文件夹，双击 `致富模拟器.exe`。不要只复制 EXE，也不要下载 `Source code` 作为运行包。
3. 进入 **A 股回放**，点击「随机抽取」，用「下一根」推进行情，再进行模拟买卖。

适用 **Windows 10/11 x64**。当前版本 **1.5.2**，下载约 **230 MB**。首次下载和解压需要时间，之后本地训练无需反复下载历史数据。
